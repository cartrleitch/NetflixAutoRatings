# Purpose, background, and features
Netflix tries to make skipping opening credits and closing credits easy by simply clicking a button. However, for me, that was still too much work, so I made this program to click those buttons for me.
Also, inspired by seriesgraph.com, this program will display the IMDb ratings for the episode currently being watching, so you will know what you're in for. Even has session summary statistics, so you know how good what you just watched was. 

# Requirements
Requires (from https://datasets.imdbws.com/):  
title.basics.tsv  
title.episode.tsv  
title.ratings.tsv  


MUST have Netflix at 100% scale on 1080p or 125% on 4k.  
Needs Tesseract installed for OCR.
